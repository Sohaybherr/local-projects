    <deadline>{data($t/@deadline)}</deadline>

7️⃣ Paragraphes contenant <important>

8️⃣ Pour chaque TODO : titre + nombre total d’items
for $t in //todo
return
  <todo>
    <title>{data($t/title)}</title>
    <nbItems>{count($t/items/item)}</nbItems>
  </todo>

9️⃣ Toutes les dates triées (ordre croissant)
for $d in //date
order by xs:date($d)
return $d
