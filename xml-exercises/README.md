# XML, DTD, XSD and XSLT Exercises

Markup exercises covering XML documents, DTD and XSD schemas, XSLT stylesheets, and XPath/XQuery examples.

## Usage

Use an XML-aware editor or validator to inspect `.xml`, `.dtd`, and `.xsd` files. Apply `.xsl` stylesheets using an XSLT processor; XPath and XQuery examples need a compatible query engine.

The `tp1` through `tp6`, `td3`, `ex_train`, and `training` folders contain separate exercises. Some documents depend on relative schema or stylesheet paths, so preserve their folder structure. Duplicate `Ensemble_Colle` materials, reports, and office documents were excluded. These are independent coursework documents without a single application entry point.
