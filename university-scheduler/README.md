# University Scheduling Model

## Overview

An unfinished Java model for students, instructors, courses, sections, and time slots, with scheduling utilities.

## Academic Objectives

Develop an object-oriented representation of entities involved in university scheduling.

## Methodology and Implementation

The source separates courses, instructors, students, sections, and time slots into Java classes, with scheduling utilities in a separate package. Application entry classes are placeholders; the model does not constitute an operational scheduler.

## Source Organization

- `src/classes/`: domain entities.
- `src/util/`: scheduling utilities.
- `src/app/`: incomplete application layer.

## Environment and Execution

Requirements: a JDK. Sources are grouped under `src/classes`, `src/util`, and `src/app`.

Open the project in a Java IDE to inspect the model. The `app.main` and `app.menu` classes are placeholders without executable entry points. This snapshot is coursework in progress, not a runnable scheduling application.
